# Sprint 8 Overlay Click-Through Smoke

## Цель

Проверить, что тестовое overlay-окно Game Translator отображается поверх других окон, остаётся прозрачным, не появляется в taskbar и не блокирует ввод в приложение под ним.

## Предусловия

- Windows 11.
- Репозиторий собран в `Release`.
- Открыто обычное desktop-приложение с интерактивными элементами под overlay, например Notepad.
- Проверка выполняется в оконном или borderless fullscreen сценарии. Exclusive fullscreen не является обязательным для MVP.

## Шаги

1. Запустить `src/GameTranslator.UI/bin/Release/net9.0-windows10.0.19041.0/GameTranslator.UI.exe`.
2. В главном окне нажать `Show test overlay`.
3. Убедиться, что поверх рабочего стола виден тестовый текст overlay.
4. Переключиться на окно под overlay и кликнуть по его полям или кнопкам через область тестового текста.
5. Убедиться, что нижнее окно получает ввод, а overlay не перехватывает клики и фокус.
6. Убедиться, что overlay не отображается как отдельная кнопка taskbar.
7. Вернуться в Game Translator и нажать `Hide overlay`.
8. Убедиться, что тестовый overlay исчез.

## Ожидаемый результат

- Overlay отображает тестовый текст поверх других окон.
- Overlay остаётся прозрачным вокруг тестового текста.
- Overlay является click-through и не блокирует нижнее окно.
- Overlay можно показать и скрыть из приложения.
- В этой проверке не требуется перевод, маскирование оригинального текста или привязка overlay к OCR bounding boxes. Эти части относятся к следующим спринтам.
