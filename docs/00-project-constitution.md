# PROJECT CONSTITUTION v1.0

## Проект

Game Translator

Система распознавания и перевода текста в компьютерных играх в режиме реального времени для Windows 11.

Статус документа: ОБЯЗАТЕЛЬНЫЙ К ИСПОЛНЕНИЮ

Версия: 1.0

---

# 1. НАЗНАЧЕНИЕ ДОКУМЕНТА

Данный документ определяет неизменяемые правила проекта.

Все участники разработки, включая AI-агентов, обязаны соблюдать данные правила.

Нарушение любого пункта Конституции требует явного согласования владельца проекта.

---

# 2. ПРИОРИТЕТ ДОКУМЕНТА

Приоритет документов:

1. Project Constitution
2. Техническое задание

Если решение противоречит Конституции — решение считается запрещённым.

---

# 3. ЦЕЛЬ ПРОЕКТА

Создать приложение Windows 11, которое:

* захватывает экран;
* распознаёт текст;
* переводит текст;
* скрывает оригинальный текст;
* отображает перевод поверх игры;
* работает в режиме реального времени;
* не взаимодействует с памятью игры.

---

# 5. ЗАПРЕЩЁННЫЕ ТЕХНОЛОГИИ

Запрещено внедрять:

* DLL Injection
* Memory Injection
* Memory Reading
* Process Hooking
* Driver Injection
* Kernel Drivers
* Anti-Cheat Bypass
* Reverse Engineering игровых процессов
* Чтение памяти игры
* Изменение памяти игры

Любые предложения таких решений должны отклоняться автоматически.

---

# 6. ПРИНЦИП РАБОТЫ

Приложение работает исключительно через:

Screen Capture
→ OCR
→ Translation
→ Overlay

Никаких альтернативных механизмов получения текста из игры использовать нельзя.

---

Слои системы:

Presentation

Application

Domain

Infrastructure

Зависимости разрешены только сверху вниз.

Запрещено:

Infrastructure → UI

Domain → Infrastructure

Domain → UI

Создание циклических зависимостей запрещено.

---

# 8. ПРАВИЛО ИНТЕРФЕЙСОВ

Любая внешняя функциональность подключается через интерфейсы.

Примеры:

IOcrEngine

ITranslatorProvider

ICaptureService

IOverlayService

ICredentialStorage

ICacheRepository

Запрещены прямые зависимости на конкретные реализации.

---

# 9. ПРАВИЛО OCR

Минимум два OCR-движка:

1. Windows OCR
2. Tesseract OCR

Запрещено:

* удалять один из движков;
* делать систему зависимой от одного OCR.

Для вертикального текста:

Только Tesseract.

Без исключений.

---

# 10. ПРАВИЛО ПЕРЕВОДЧИКОВ

Минимально поддерживаемые провайдеры:

* Google
* Azure
* Yandex

Каждый провайдер обязан реализовывать:

ITranslatorProvider

Замена архитектуры переводчиков запрещена.

---

# 11. ПРАВИЛО КЭША

Перед обращением к API:

обязательная проверка кэша.

Архитектура кэша:

Memory Cache
+
SQLite Cache

TTL:

30 дней

Изменение TTL по умолчанию требует согласования.

* SQLite
* XML

* Конфигурационные файлы

# 13. ПРАВИЛО OCR-ЗОН

Каждая OCR-зона обязана содержать:

Абсолютные координаты

Относительные координаты

Пересечение OCR-зон запрещено.

Профиль с пересечением не может быть сохранён.

---

# 14. ПРАВИЛО OVERLAY

Overlay является отдельным независимым модулем.

Запрещено:

* встраивать Overlay в OCR;
* встраивать Overlay в переводчики;
* смешивать ответственность модулей.

Обязательные слои:

OCR Layer

Mask Layer

Translation Layer

Debug Layer

---

# 15. ПРАВИЛО МАСКИРОВАНИЯ

Разрешённые режимы:

Solid

Darken

Запрещено:

Blur

Content Aware Fill

# 16. ПРАВИЛО МНОГОЗОННОСТИ

Все новые функции обязаны работать с несколькими OCR-зонами.

Решения, работающие только с одной зоной, считаются дефектом архитектуры.

---

schemaVersion
