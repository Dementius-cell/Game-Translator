# Issue tracker: GitHub

Issues and PRDs for this repo live in GitHub Issues for `Dementius-cell/Game-Translator`.

## Repository

- Owner: `Dementius-cell`
- Repository: `Game-Translator`
- Default branch: `main`
- Issue tracker: GitHub Issues

## Conventions

- Use GitHub Issues for implementation tasks, bugs, feature requests, and PRD follow-up work.
- Use issue labels from `triage-labels.md` for triage state.
- Link implementation PRs back to their issue with GitHub closing keywords when appropriate.
- Keep issue bodies aligned with the roadmap, sprint plan, quality gates, and AI development rules in `docs/`.

## When a skill says "publish to the issue tracker"

Create or update a GitHub issue in `Dementius-cell/Game-Translator`.

Prefer the GitHub CLI when available:

```bash
gh issue create --repo Dementius-cell/Game-Translator
```

## When a skill says "fetch the relevant ticket"

Read the referenced GitHub issue from `Dementius-cell/Game-Translator`.

Prefer the GitHub CLI when available:

```bash
gh issue view <number> --repo Dementius-cell/Game-Translator
```
