# ГЛАВНАЯ ЦЕЛЬ

Разработать приложение Windows 11, которое:

1. Захватывает заданные области экрана.
2. Выполняет OCR текста.
3. Переводит текст через выбранный сервис.
4. Скрывает оригинальный текст.
5. Показывает перевод поверх игры.
6. Работает в режиме реального времени.
7. Не взаимодействует с памятью игры.
8. Не использует инъекции.
9. Не нарушает работу античитов.

# ПРАВИЛО OCR

Каждый OCR движок обязан реализовывать:

Минимальные методы:

DetectTextBlocks()

GetBoundingBoxes()

Для вертикального японского и китайского текста использовать только Tesseract.
