# Пошаговый план разработки по спринтам

## Detailed Sprint Development Plan

Проект: Система экранного OCR-перевода игровых субтитров и текста для Windows 11

Продолжительность спринта: 1 неделя

Общее количество спринтов MVP: 24-26 (обновлено)

------------------------------------------------------------------------

# Sprint 0: Инициализация проекта

Создать решение GameTranslator.sln, проекты (UI, Application, Domain, Infrastructure, Tests). Настроить .NET 9, WPF, MVVM, DI, Serilog. Результат: пустое приложение WPF запускается.

------------------------------------------------------------------------

# Sprint 1: Базовая архитектура

Реализовать INavigationService, IDialogService, ISettingsService, ILoggerService. Создать MainWindow, ShellView, ShellViewModel. Навигация между страницами.

------------------------------------------------------------------------

# Sprint 2: Менеджер профилей

Создать GameProfile, OcrZone, OverlaySettings, TranslatorSettings. CRUD операций, локальное сохранение.

------------------------------------------------------------------------

# Sprint 3: JSON импорт/экспорт

Экспорт/импорт профиля, проверка версии схемы, ProfileValidator.

------------------------------------------------------------------------

# Sprint 4: OCR зоны

Создание зоны мышью (аналог «Ножниц»), изменение размеров, удаление, проверка пересечений.

------------------------------------------------------------------------

# Sprint 5: Захват изображения

Windows Graphics Capture, захват области, предпросмотр, обновление 30+ FPS.

------------------------------------------------------------------------

# Sprint 6: OCR Engine Interface

Создать IOcrEngine, OcrResult, TextBlock, BoundingBox. Реализовать WindowsOcrEngine.

------------------------------------------------------------------------

# Sprint 7: OCR Debug View

Отображение Bounding Box, координат, текста.

------------------------------------------------------------------------

# Sprint 8: Overlay MVP (WPF + SharpDX)

OverlayWindow, прозрачность, click-through, always on top. Тестовый текст поверх игры.

------------------------------------------------------------------------

# Sprint 9: Overlay Positioning

Привязка к Bounding Box, автоматическое обновление координат, масштабирование.

------------------------------------------------------------------------

# Sprint 10: Переводчики

ITranslatorProvider, TranslateRequest/Response. Реализовать GoogleTranslatorProvider.

------------------------------------------------------------------------

# Sprint 11: Azure и Яндекс

AzureTranslatorProvider, YandexTranslatorProvider, TranslatorManager.

------------------------------------------------------------------------

# Sprint 12: Credential Storage

CredentialManagerService (сохранение, чтение, удаление ключей).

------------------------------------------------------------------------

# Sprint 13: Полная цепочка

Capture → OCR → Translate → Overlay. Первый полный рабочий перевод.

------------------------------------------------------------------------

# Sprint 14: Система маскирования

Маска Solid/Darken (без blur). Настройки: цвет, opacity, padding.

------------------------------------------------------------------------

# Sprint 15: Кэш переводов

TranslationCache, CacheRepository, Memory Cache, SQLite Cache. TTL 30 дней, ручная очистка.

------------------------------------------------------------------------

# Sprint 16: Горячие клавиши

Регистрация глобальных хоткеев: старт/пауза, показать/скрыть overlay, настройки, выход.

------------------------------------------------------------------------

# Sprint 17: Отладочный режим

Debug Overlay, статистика, тайминги (OCR, Translate, Render, FPS, CPU, RAM).

------------------------------------------------------------------------

# Sprint 18: Настраиваемый OCR

Контраст, яркость, резкость, бинаризация, шумоподавление.

------------------------------------------------------------------------

# Sprint 19: Многозонный режим

Одновременная работа нескольких зон, независимые результаты и overlay.

------------------------------------------------------------------------

# Sprint 20: Tesseract OCR

TesseractOcrEngine, переключение OCR. **Обязателен для вертикального текста.**

------------------------------------------------------------------------

# Sprint 21: Определение направления текста

OrientationDetector (Auto, Horizontal, Vertical).

------------------------------------------------------------------------

# Sprint 22: Японский и китайский текст

Поддержка Tategaki, Yokogaki, Traditional/Simplified Chinese. Использовать только Tesseract.

------------------------------------------------------------------------

# Sprint 23: Оптимизация производительности

Frame Difference Detection, OCR/Translation debouncing. Достичь целей: CPU ≤25% средний, RAM ≤500 МБ.

------------------------------------------------------------------------

# Sprint 24: Автообновление

Интеграция Squirrel.Windows. Проверка обновлений при старте, ручная проверка.

------------------------------------------------------------------------

# Sprint 25: Тестирование совместимости

Проверка на статичных скриншотах, разрешениях 1920×1080, 2560×1440, 3840×2160, оконный и borderless fullscreen.

------------------------------------------------------------------------

# Sprint 26: Beta Release

Исправление критических ошибок, утечек памяти, ошибок интерфейса.

------------------------------------------------------------------------

# Sprint 27: Release Candidate

Подготовка документации, справки, настроек по умолчанию.

------------------------------------------------------------------------

# Sprint 28: Release 1.0

Установщик, сборка, документация. Состав релиза: профили игр, JSON импорт/экспорт, три переводчика, Windows OCR + Tesseract, overlay, многозонность, горячие клавиши, кэш (TTL 30 дней), режим отладки, вертикальный текст, автообновление.

------------------------------------------------------------------------

# Обязательное правило для ИИ-агента

После каждого спринта агент обязан предоставить: список изменённых файлов, новых файлов, реализованные функции, нереализованные функции, выявленные риски, предложение по следующему спринту, обновлённый статус проекта (% готовности).
