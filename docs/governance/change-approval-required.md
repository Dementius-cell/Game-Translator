# CHANGE_APPROVAL_REQUIRED.md

# Change Approval Required

Проект: Game Translator

Версия: 1.0

Статус: ACTIVE

---

# Назначение документа

Данный документ определяет изменения, которые AI-агент НЕ имеет права выполнять самостоятельно.

Перед выполнением любого изменения из списка агент обязан:

1. Остановить выполнение задачи.
2. Подготовить предложение на изменение (Change Request).
3. Описать последствия.
4. Дождаться явного одобрения владельца проекта.

До получения одобрения изменение считается запрещённым.

---

# ОБЯЗАТЕЛЬНОЕ ПРАВИЛО ДЛЯ AI-АГЕНТА

Перед любым потенциально опасным изменением агент обязан проверить:

1. Project Constitution
2. Architecture Decision Records (ADR)
3. Change Approval Required
4. Техническое задание
5. Roadmap

Если изменение найдено в данном документе:

выполнение запрещено до получения разрешения владельца проекта.

---

# ФИНАЛЬНОЕ ПРАВИЛО

Если существует сомнение, требуется ли согласование:

считать, что согласование требуется.

Безопасность и стабильность проекта имеют приоритет над скоростью разработки.
